# Case-Time-to-find 🔎

## About the Project

Case-Time-to-find is a browser-based detective investigation game where players solve mysteries by examining evidence, selecting suspects, and making accusations before time runs out.

The game features a Detective Noir atmosphere and interactive investigation phases.

## Live Demo

Play the game here: https://case-time-to-find.vercel.app/

## Features

* Seven selectable mystery cases
* Three difficulty levels: Easy, Standard, and Hard
* Countdown timer and scoring system
* Interactive evidence inspection with time penalties
* Suspect selection and accusation mechanics
* Two investigation phases: Missing Person and Murder Investigation
* Case-specific clues, suspects, and outcomes
* Game reset functionality
* Responsive user interface

## Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript

## How to Play

1. Open the game using the Live Demo link.
2. Select a mystery case and difficulty level.
3. Examine the available evidence and review the suspects.
4. Manage your remaining time while investigating.
5. Select a suspect and submit your accusation.
6. Solve the investigation before time runs out.

## How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start investigating.

No installation or external dependencies are required.

## Deployment

The game is deployed using Vercel and can be accessed through the Live Demo link above.
